# Photo Album

React 18 and TypeScript frontend built with Vite and Tailwind CSS.

## Run on Replit

- Install dependencies with `npm install`.
- Start the development server with `npm run dev`.
- The app binds to `0.0.0.0:5000` and allows Replit's proxied preview hosts.
- Check types with `npm run lint`.
- Create a production build with `npm run build`.

The current frontend does not require any external service credentials.
